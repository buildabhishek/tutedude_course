## 🔐 API Keys & Secrets

API keys and other sensitive credentials should **not** be committed to this repository.

For assignments requiring environment variables, use a local `.env` file and keep secrets outside version control.

Example:

```env
OPENAI_API_KEY=your_api_key_here
```

Never commit real API keys, passwords, tokens, or other credentials.

## 🚀 Running an Assignment

Most Python-based assignments can be run from their respective assignment directory.

For example:

```powershell
cd GenAI-Task29-AbhishekThakare
```

Install the required dependencies:

```powershell
pip install -r requirements.txt
```

Then run the relevant Python application or notebook.

For example:

```powershell
python app\openai_chat.py
```

> Individual assignment folders may have different setup and execution instructions. Check the files inside each assignment folder before running it.
